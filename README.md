# QA Commerce Lab

E-commerce desenvolvido como laboratório para estudo e prática de Quality Assurance e automação de testes.

## Objetivo

Construir uma aplicação de e-commerce funcional que permita praticar diferentes níveis de teste em um ambiente controlado.

O projeto será utilizado para estudos de:

- testes E2E;
- testes de API;
- validações de banco de dados;
- automação com Playwright;
- testes funcionais e exploratórios;
- regressão;
- criação e documentação de bugs;
- integração contínua.

## Tecnologias previstas

- React
- TypeScript
- Node.js
- Express
- PostgreSQL
- Docker
- Docker Compose
- Playwright
- GitHub Actions

## QA Bug Lab

O projeto contará com defeitos intencionais que poderão ser habilitados em ambiente de teste.

Esses defeitos serão documentados e utilizados para exercícios de identificação, reprodução e automação de testes.
